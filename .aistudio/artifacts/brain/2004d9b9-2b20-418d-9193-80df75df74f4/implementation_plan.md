# خطة تطوير النظام المحاسبي وإدارة المصاريف العائلية - محمد طالب

نظام محاسبي وإداري متطور، عالي الأداء ومنظم هندسياً بالكامل باستخدام React 19 وTypeScript وTailwind CSS، مخصص لإدارة الدخل الشهري، مشتريات الخضار، اللحوم والأسماك، مواد الهري (التموين)، وفواتير ومصاريف المعيشة بالدرهم المغربي مع حفظ محلي دقيق، تحليلات بصرية، وتصدير للبيانات.

---

## مراجعة القرارات والتوجيهات التقنية

> [!IMPORTANT]
> تم أخذ الكود الأصلي والميزات الحالية بعين الاعتبار لتحويل المنظومة من صفحة أحادية غير منظمة تعتمد على معالجة الـ DOM اليدوية و `innerHTML` و `alert/confirm`، إلى هيكلية معيارية موحدة من مكونات React مع إدارة حالة (State Management) آمنة وسريعة بدون أي تسريب للذاكرة.

- **الهيكلية البرمجية المقررة**: تطبيق React + TypeScript حديث ومتكامل يعتمد على تصميم مكونات متداخلة ونظيفة (Modular Components) مع معايير Tailwind CSS المعاصرة.
- **تخزين البيانات**: حفظ محلي تلقائي وفوري (`localStorage`) بدون فقدان لأي تغيير، مع توفير خاصية التصدير والاستيراد (JSON / CSV) للنسخ الاحتياطي في أي وقت.
- **التوافق والاستخدام**: دعم كامل للغة العربية واتجاه اليمين لليسار (`dir="rtl"`) مع تجربة استخدام متجاوبة ومثالية لكل من أجهزة الجوال وشاشات الحواسيب ولوحات التحكم.

## 1. نظرة عامة والهدف الوظيفي

يهدف التطوير إلى نقل التطبيق الحالي إلى مستوى احترافي يحقق:
1. **أداء فائق واستقرار تام**: استبدال كافة التوابع العشوائية القديمة بنموذج بيانات موحد (`TypeScript Interfaces`) يضمن سلامة المعاملات الحسابية (تجنب أخطاء الفاصلة العشرية، التحقق الصارم من الأرقام والكميات).
2. **شامل لكافة الأقسام المعتمدة**:
   - **الدخل والراتب**: تتبع مصادر الدخل المتعددة، الراتب الأساسي، والمكافآت مع صافي الأرباح.
   - **سوق الخضار والفواكه**: قائمة غنية من الخضار الافتراضية مع إمكانية إضافة أصناف جديدة وحساب السعر × الكمية بدقة.
   - **اللحوم والأسماك والدواجن**: دعم تصنيفات اللحوم، الأسماك، والدواجن مع الأوزان والأسعار الفورية.
   - **قسم الهري (المواد التموينية والغذائية)**: تتبع المؤن والزيوت والدقيق والسكر والشاي وغيرها من المواد المنزلية.
   - **الفواتير والمصاريف الثابتة والطارئة**: الماء والكهرباء والإنترنت والغاز والمصاريف الأخرى.
   - **لوحة الملخص الذكي والتحليلات**: بطاقات مؤشرات الأداء المالي (KPIs)، مؤشر نسبة الإنفاق من الدخل، ورسم بياني تفاعلي لتوزيع المصاريف ونسبة التوفير المحققة.
3. **أدوات مساعدة جديدة**:
   - البحث السريع والفلترة داخل كل قسم.
   - نافذة تعديل احترافية بدلاً من مربعات النص المتداخلة.
   - تصدير تقرير الحسابات إلى ملف (JSON للنسخ الاحتياطي و CSV متوافق مع Excel).
   - إمكانية تصفير أو بدء شهر محاسبي جديد مع أرشفة السجلات السابقة.

## 2. تجربة المستخدم والتصميم البصري (UX & Visual Design)

- **الاتجاه والخط**: واجهة عربية أصيلة (`dir="rtl"`) مع خط `Tajawal` العربي المعتمد والمريح للقراءة، مع استخدام أرقام جدولية (`tabular-nums`) للحفاظ على تناسق الأعمدة والأرقام المالية.
- **نظام الألوان (60-30-10)**:
  - **60% الخلفية والمساحات الأساسية**: درجات رمادي ثلجي/سماوي هادئ ونظيف (`#f8fafc` و `#f0fdf4` / `#f0f9ff`).
  - **30% الأسطح والبطاقات**: بطاقات بيضاء نقية مع حدود دقيقة (`border border-slate-200`) وظلال خفيفة، وأقسام واضحة بدون تراكم بصري.
  - **10% لهجات التمييز والحالة**:
    - الأزرق المحيطي (`#0284c7` / `#0369a1`) للعلامة التجارية والأزرار الأساسية.
    - الأخضر الزمردي (`#16a34a`) للدخل والأرباح والمتبقي الإيجابي.
    - الكهرماني (`#d97706`) للمصاريف المتوسطة والتنبيهات.
    - الوردي/الأحمر الصريح (`#dc2626`) للتنبيه بتجاوز الميزانية أو عمليات الحذف المؤكدة.
- **التنقل (Navigation)**:
  - **للشاشات الكبيرة**: شريط تنقل علوي وشريط أقسام (Tabs) أنيق ومريح للتنقل السريع بين الأقسام الستة، مع عرض إحصائيات سريعة في الشريط العلوي.
  - **للجوال**: شريط تنقل سفلي مثبت (Bottom Navigation) مرن وسهل اللمس بأيقونات واضحة مع إمكانية التمرير والانتقال بلمسة واحدة.
- **التفاعل والملاحظات (Feedback & Dialogs)**:
  - استبدال دوال المتصفح البدائية (`alert`, `confirm`, `prompt`) بنوافذ حوارية مدمجة وأنيقة (Modals) لتأكيد الحذف وإضافة عناصر جديدة للقوائم المنسدلة.
  - تنبيهات لطيفة (Toast notifications) عند إتمام الحفظ أو التصدير بنجاح.

## 3. القرارات التقنية والهندسية

| العنصر | النهج المعتمد | السبب والفائدة |
| :--- | :--- | :--- |
| **إدارة الحالة (State)** | React Custom Hooks (`useAccountingStore`) | فصل منطق البيانات عن واجهة المستخدم، مما يتيح التعديل المستقبلي وسهولة الاختبار والصيانة. |
| **الحفظ الدائم** | LocalStorage مع Migration تلقائي | الحفاظ على بيانات المستخدم الحالية دون أي فقدان عند الترقية إلى النسخة الجديدة. |
| **الحسابات المالية** | دالة مخصصة مع تقريب رقمي صارم (`roundTo2`) | منع مشكلات الفاصلة العائمة (Floating-point precision issues) في الجافاسكريبت. |
| **الرسوم البيانية** | مكون SVG تفاعلي أصيل خفيف الوزن | تقديم مخطط شريطي ومخطط دائري (Donut Chart) يوضح نسب الصرف دون الحاجة لتثبيت مكتبات ثقيلة تبطئ المتصفح. |
| **الأمان والتأكيد** | نوافذ تأكيد مدمجة لكافة عمليات الحذف | تفادي الحذف العرضي أو فقدان السجلات غير المقصود. |

## 5. خطة التنفيذ خطوة بخطوة

1. **الخطوة 1 - بناء نواة البيانات والأنواع (`types.ts` & `useAccounting.ts`)**:
   - تعريف كافة الواجهات البرمجية وتجهيز البيانات الافتراضية الأولية بنفس أسماء وقوائم الكود الأصلي لمحمد طالب (الطماطم، البطاطس، لحم، سمك، دجاج، زيت الزيتون، سكر، وغيرها).
   - بناء منطق المزامنة مع `localStorage` مع دعم الترحيل التلقائي من النسخة القديمة إن وجدت.
2. **الخطوة 2 - المكونات المشتركة والتحكم البصري**:
   - بناء بطاقات العرض مع أزرار التعديل والحذف السريع.
   - بناء نماذج إدخال متجاوبة وسريعة التدقيق تمنع الإدخال الخاطئ.
   - نافذة الحوار الموحدة (Modal) لإضافة مواد جديدة أو تأكيد الحذف الشامل.
3. **الخطوة 3 - بناء شاشات الأقسام**:
   - شاشة الدخل والراتب.
   - شاشات مشتريات الخضار، اللحوم، والهري مع حساب المجموع التلقائي (`السعر × الكمية`).
   - شاشة الفواتير والمصاريف.
4. **الخطوة 4 - لوحة الملخص البياني والإحصائيات الذكية**:
   - بطاقات إحصائية بارزة للمجموع الإجمالي للدخل، المشتريات، والمتبقي الصافي.
   - رسم بياني يوضح النسب المئوية لتوزيع النفقات (خضار vs لحوم vs تموين vs فواتير).
   - مؤشر كفاءة التوفير والتنبيه إذا كانت النفقات تتجاوز الدخل.
5. **الخطوة 5 - ميزات التصدير والنسخ الاحتياطي وتحديث index.html**:
   - تصدير كملف JSON واستيراد ملف محفوظ.
   - تصدير جدول البيانات كملف CSV مناسب لـ Excel.
   - ضبط عنونة التطبيق وأوصاف محركات البحث والخط العربي في `index.html` و `metadata.json`.
6. **الخطوة 6 - التحقق البرمجي والتجميع**:
   - تشغيل `compile_applet` للتأكد من خلو المشروع من أية أخطاء تجميع وتوافقه الكامل.
